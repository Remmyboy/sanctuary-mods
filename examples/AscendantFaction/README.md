# Ascendant: a fourth faction (proof of concept)

A gameplay mod that adds a faction to the lobby's faction dropdown. It was tested
in a match on game 0.0.1.20. You pick Ascendant, spawn its commander, and the
commander builds an Ascendant land factory, which builds Ascendant tanks and
raiders. All of it uses EDA's models.

| Id | Made from | Notes |
| --- | --- | --- |
| `ual0000` | `uel0000` commander | starting unit |
| `ual1501` | `uel1501` T1 engineer | |
| `ual1001` | `uel1001` T1 tank | 420 health (EDA 275), speed 2.9 (EDA 3.3) |
| `ual1002` | `uel1002` T1 raider | |
| `uas1511` | `ues1511` T1 land factory | no upgrade |
| `uas1601` | `ues1601` T1 alloy extractor | no upgrade |
| `uas1611` | `ues1611` T1 energy generator | |

## What's in it

- `lua\append\common\systems\factions.lua`: faction 4 (name, `ua` id prefix,
  `ASCENDANT` tag, starting unit).
- `lua\common\units\unitsTemplates\*`: the units, generated by
  `tools\make-templates.ps1` from the game's EDA templates.
- `lua\append\common\loading\placementGhostTemplateLoader.lua`: placement
  ghosts borrow the model named by `general.modelTpId`, as the units do.
- `lua\append\client\ui\uiUtils.lua`: portraits borrow the model unit's too.
  Without it the build buttons show "coming soon", and SanctuaryHud hides them.
- `AscendantLobby.cs`: the DLL. It adds "Ascendant" to every lobby row's
  faction dropdown while the mod is picked. If the mod is dropped, it takes the
  option away again and moves anyone on Ascendant back to EDA.

## Build and try

```bash
dotnet build
```

That compiles the DLL and copies the DLL, `mod.json` and `lua\` into
`engine\SanctuaryMods\AscendantFaction`. In a lobby, the host picks the mod
from the Mods panel, then anyone can choose Ascendant as their faction.

After a game update, run `pwsh -File tools/make-templates.ps1` to regenerate the
units from the current EDA ones.

## Known limits

- **Art:** new models, textures and effects need the game's asset packs, which
  mods can't reach, so every unit borrows EDA art.
- **AI:** an AI can't play Ascendant.
- **Materials:** shields, build beams and adjacency effects fall back to
  EDA's, and the game logs a "no faction tag" line for each unit.
- **Vanilla players:** someone without the mod who is in the lobby when a
  player picks Ascendant receives a faction number their dropdown doesn't
  have. Start is blocked for them anyway, since they lack the mod.
- **Repeat build:** the factory inherits EDA's repeat-build default.
